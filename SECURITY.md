## Reporting a Vulnerability

We take the security of the **Platione Sales Assist QA Automation Framework** seriously. If you discover a vulnerability or security flaw, please report it responsibly.

### How to Report

1. **Private Vulnerability Reporting (Recommended):**
   - Navigate to the **Security** tab of this repository on GitHub.
   - Click on **Report a vulnerability** under the Advisories section to privately submit a report directly to the maintainers.

2. **Email Disclosure:**
   - If you cannot use GitHub Private Vulnerability Reporting, please email your findings to `shlokthorat926@gmail.com` (or the repository owner).
   - Please include:
     - Description of the issue and potential impact
     - Clear step-by-step reproduction steps or Proof of Concept (PoC)
     - Any suggested mitigations or patches

### Response SLA & Process

- **Initial Response:** Within 48 hours acknowledging receipt of your report.
- **Assessment & Triage:** Within 5 business days with vulnerability verification.
- **Fix & Advisory:** A patch will be prepared and released alongside a GitHub Security Advisory crediting the reporter (unless anonymity is requested).

> [!CAUTION]
> Please do **not** open public GitHub issues or discussions for undisclosed security vulnerabilities.
