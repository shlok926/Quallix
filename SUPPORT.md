# Support & Getting Help

Thank you for using the **Platione Sales Assist QA Automation Framework**! Here are the recommended ways to get support, report bugs, or ask questions:

## 1. Documentation

Before opening an issue, check the existing documentation:
- [README.md](README.md) - Project overview, test architecture, and setup instructions.
- [CONTRIBUTING.md](CONTRIBUTING.md) - Guidelines for extending tests, page objects, fixtures, and best practices.

## 2. GitHub Issues

- **Bug Reports:** If you encountered unexpected behavior or test failures, check existing issues or [open a new Bug Report](https://github.com/shlok926/Quallix/issues/new?template=bug_report.md).
- **Feature Requests:** Want a new test suite, fixture helper, or CI feature? [Submit a Feature Request](https://github.com/shlok926/Quallix/issues/new?template=feature_request.md).

## 3. Security Vulnerabilities

If you discovered a security issue, please **do not open a public issue**. Follow the instructions in [SECURITY.md](SECURITY.md) to report privately.
